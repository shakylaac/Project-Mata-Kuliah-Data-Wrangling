# Analisis Pengaruh Akses Internet, Pengeluaran Per Kapita, dan Konsumsi Telekomunikasi terhadap Partisipasi Sekolah pada Provinsi di Indonesia Tahun 2018–2023

## Deskripsi Proyek
Proyek ini merupakan tugas mata kuliah **Data Wrangling** pada program studi S1 Sains Data. Proyek ini membahas hubungan antara akses internet, pengeluaran per kapita, dan konsumsi telekomunikasi dengan partisipasi sekolah di berbagai provinsi di Indonesia selama periode 2018–2023.
Analisis ini berfokus pada pemanfaatan data untuk memahami keterkaitan antara perkembangan akses digital, kondisi ekonomi masyarakat, dan partisipasi pendidikan di Indonesia.

## Tujuan
- Mempelajari karakteristik data akses internet, pengeluaran per kapita, konsumsi telekomunikasi, dan partisipasi sekolah.
- Menyiapkan dan mengolah data agar dapat digunakan untuk analisis.
- Menganalisis hubungan antara indikator akses digital dan ekonomi dengan partisipasi sekolah.
- Mengamati pola perubahan indikator selama periode 2018–2023 di berbagai provinsi Indonesia.

## Variabel yang Digunakan

| Variabel | Peran |
|---|---|
| Akses Internet | Variabel independen |
| Pengeluaran Per Kapita | Variabel independen |
| Konsumsi Telekomunikasi | Variabel independen |
| Partisipasi Sekolah | Variabel dependen |

## Cakupan Data
- **Wilayah:** Provinsi di Indonesia
- **Periode:** 2018–2023
- **Topik:** Pendidikan, akses digital, dan kondisi ekonomi masyarakat

## Tahapan Pengerjaan
Secara umum, proyek Data Wrangling ini berkaitan dengan tahapan pengolahan data sebelum analisis. Dokumentasi tahapan berikut dapat disesuaikan dengan pengerjaan aktual proyek.
1. **Pengumpulan Data**  
   Mengumpulkan data yang berkaitan dengan indikator akses internet, pengeluaran per kapita, konsumsi telekomunikasi, dan partisipasi sekolah.
2. **Data Cleaning**  
   Memeriksa kualitas data, termasuk kemungkinan nilai kosong, duplikasi, dan ketidakkonsistenan format.
3. **Data Transformation**  
   Menyesuaikan format dan struktur data agar indikator dapat dianalisis berdasarkan provinsi dan tahun.
4. **Data Integration**  
   Menggabungkan data dari sumber yang berbeda apabila diperlukan, dengan memperhatikan kesesuaian wilayah dan periode.
5. **Exploratory Data Analysis (EDA)**  
   Mengeksplorasi karakteristik data dan pola hubungan antarvariabel sebagai dasar analisis lebih lanjut.

## Hasil dan Temuan
Bagian ini dapat dilengkapi dengan hasil pengolahan data, visualisasi, dan temuan utama setelah hasil proyek asli tersedia.
